Resources

Cybersecurity is an occasional hobby of mine. I am mostly self taught but was lucky to receive some additional mentorship during engineering work terms. The podcast Darknet Diaries was probably the first thing to pique my interest, and I definitely recommend it. Hacked is another great one by some fellow Canadians.

Bug Bounty

While learning about Shodan I came across a broken access control vulnerability mostly by sheer luck. This was good practice for responsible disclosure and the issue has thankfully been fixed. I got my name added to the UNICEF Information Security Hall of Fame which was cool.

Flipper Zero

This tool is fun but I think the main use for it is demonstrating that if you make objects smarter they get really hackable. I also added a SubGHz modulation shortcut feature to the firmware for a course project in open-source contribution, which they did not integrate and that is fine.
